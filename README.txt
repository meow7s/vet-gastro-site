VETGUT — демо-сайт ветеринарного гастроэнтеролога и диетолога

Файлы:
- index.html — содержание страницы
- styles.css — дизайн и адаптив
- script.js — мобильное меню и FAQ

Как посмотреть:
1. Откройте index.html двойным кликом в браузере.
2. Для публикации можно загрузить папку на Netlify, Vercel, GitHub Pages или любой обычный хостинг.

Что лучше заменить:
- Название VETGUT на ваш бренд / имя.
- Блок-заглушку «здесь можно поставить ваше фото» на реальную фотографию.
- Ссылки Telegram / WhatsApp в секции «Запись».
- Демо-отзывы на реальные.
- Стоимость услуг при необходимости.
- Юридическую информацию / политику конфиденциальности, если на сайте будет форма сбора данных.

Дизайн:
- тёплый молочный фон
- тёмно-синий текст
- коралловый, лавандовый, голубой и жёлтый акценты
- крупная типографика
- карточки, круглые формы, pet-friendly стилистика
- адаптация под мобильный экран
